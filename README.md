## Работа 4. Перечисления

### 1. Времена года

Перечисление `Season` содержит четыре значения: `WINTER`, `SPRING`, `SUMMER`, `AUTUMN`. У каждого значения хранится средняя температура, которая задается через конструктор.

Метод `getDescription()` возвращает описание сезона. Для лета он переопределен и возвращает «Теплое время года», для остальных сезонов возвращается «Холодное время года», как требуется в задании.

В `TestSeason` выбирается любимое время года. Метод `love()` через `switch` выводит соответствующее сообщение. Затем программа перебирает `Season.values()` и показывает температуру и описание всех сезонов. Температуры заданы как учебный пример.

### 2. Ателье

Перечисление `Size` содержит размеры от `XXS` до `L` и соответствующие европейские размеры от `32` до `40`. Для `XXS` метод `getDescription()` возвращает «Детский размер», для остальных возвращает «Взрослый размер».

Абстрактный класс `Clothes` хранит размер, цену и цвет одежды. От него наследуются четыре класса:

| Класс | Объект | Реализуемые интерфейсы |
| --- | --- | --- |
| `TShirt` | Футболка | `MenClothing`, `WomenClothing` |
| `Pants` | Штаны | `MenClothing`, `WomenClothing` |
| `Skirt` | Юбка | `WomenClothing` |
| `Tie` | Галстук | `MenClothing` |

В `Atelier` создается массив `Clothes[]` со всеми видами одежды. Методы `dressMan()` и `dressWomen()` перебирают массив и через `instanceof` выбирают подходящие вещи. Затем вызывается метод нужного интерфейса, который выводит сведения об одежде.

### 3. Интернет-магазин

`Category` содержит категории товаров: книги, электроника и одежда. `Product` описывает товар: название, цену и категорию. `Shop` хранит список товаров, корзину и объект `Scanner` для чтения команд пользователя.

Сначала пользователь вводит логин и пароль. Учебные данные для входа: `student` и `java`. При неверных данных программа завершает работу.

После входа меню позволяет открыть список категорий, посмотреть товары выбранной категории, добавить товар в корзину, увидеть итоговую сумму и оформить покупку. Выбор номера товара превращается в добавление соответствующего объекта `Product` в список корзины. После покупки корзина очищается. При попытке купить пустую корзину выводится сообщение.

Проверяются неверные номера меню, категорий и товаров. Магазин работает в памяти: данные не сохраняются после закрытия, реальная оплата не выполняется.

### 4. Компьютер

Класс `Computer` содержит марку компьютера и объекты его составных частей: `Processor`, `Memory`, `Monitor`. Марка выбирается из перечисления `Brand`.

Процессор хранит модель, количество ядер и частоту. Память хранит объем и частоту. Монитор хранит диагональ и разрешение. В `TestComputer` создаются эти компоненты, затем из них собирается объект компьютера и выводятся его характеристики.

Здесь используется композиция: один объект содержит другие объекты.

## Работа 4.1. Наследование и абстрактные классы

### 1. Геометрические фигуры

В пакете `shapes` реализован обычный класс `Shape` и его наследники `Circle`, `Rectangle`, `Square`. У фигур есть методы определения типа `getType()`, расчета площади `getArea()`, периметра `getPerimeter()` и вывода описания `toString()`.

В `TestShape` круг, прямоугольник и квадрат обрабатываются через ссылки `Shape`. Для каждого объекта выполняется его реализация метода. Это демонстрирует полиморфизм. Изменение одной стороны квадрата изменяет и вторую сторону.

### 2. Телефон

`Phone` хранит номер, модель и вес телефона. В `TestPhone` создаются три объекта с помощью разных конструкторов: без параметров, с номером и моделью, со всеми тремя значениями.

Конструктор с тремя параметрами вызывает конструктор с двумя через `this(...)`, затем задает вес. Метод `getNumber()` возвращает номер телефона.

Метод `receiveCall()` перегружен: один вариант принимает имя звонящего, другой принимает имя и номер. Метод `sendMessage(String... numbers)` получает любое количество номеров и выводит их в консоль.

### 3. Человек

`Person` содержит имя `fullName` и возраст `age`. Методы `move()` и `talk()` выводят сообщения с именем человека. В `TestPerson` создаются два объекта: один с данными по умолчанию, другой с явно указанными именем и возрастом. Для обоих вызываются методы поведения.

### 4. Матрица

`Matrix` хранит двумерный массив чисел, число строк и столбцов. Конструктор копирует переданный массив, чтобы его внешнее изменение не меняло матрицу.

Метод `add()` складывает элементы матриц одинакового размера. Метод `multiply(double)` умножает каждый элемент на число. Перегруженный `multiply(Matrix)` вычисляет произведение двух матриц. Метод `print()` выводит строки матрицы.

Все вычисления возвращают новый объект `Matrix`. Исходные матрицы сохраняются. При несовместимых размерах выбрасывается `IllegalArgumentException`. В `TestMatrix` создаются две матрицы и показываются результаты трех операций.

### 5. Читатели библиотеки

`Reader` хранит ФИО читателя, номер билета, факультет, дату рождения и телефон. `Book` хранит название книги и автора.

Методы `takeBook()` и `returnBook()` перегружены. Им можно передать количество книг, несколько названий или несколько объектов `Book`. Для объектов книг программа извлекает названия и формирует сообщение о выдаче или возврате.

В `TestReader` создаются два читателя и три книги. Для каждого читателя вызываются все варианты методов. Программа демонстрирует сообщения о действиях, учет реальной выдачи и остатков книг не ведется.

### 6. Работники и менеджеры

`Employer` хранит имя, фамилию и зарплату. `Manager` наследуется от него и добавляет поле `averageSum` для доплаты за продажи.

В реализации `income` трактуется как месячная зарплата. Метод `getIncome()` возвращает доход за год: `income * 12`. Менеджер переопределяет этот метод и добавляет годовую сумму доплат: `averageSum * 12`. Здесь `averageSum` считается средней месячной доплатой.

Например, при зарплате `70000` и доплате `10000` годовой доход менеджера равен `960000`. Такое толкование выбрано потому, что в условии нет конкретных данных для расчета по рабочим дням.

В `TestEmployer` обычный работник и менеджер находятся в массиве `Employer[]`. Вызов `getIncome()` использует реализацию соответствующего объекта.

### 7. Учащиеся

`Learner` хранит имя учащегося. Его наследники `Student` и `Schoolchild` обозначают студента и школьника.

В `TestLearner` создается общий массив учащихся. Программа проверяет тип каждого объекта через `instanceof` и отдельно выводит студентов и школьников.

### 8. Абстрактные фигуры

В пакете `abstractshapes` создана отдельная версия иерархии фигур. В ней `Shape` является абстрактным и задает методы `getArea()` и `getPerimeter()`. Их реализуют конкретные наследники. `Square` использует реализацию прямоугольника и сохраняет равенство сторон.

Напрямую создать `new Shape()` нельзя. Методы вроде `getRadius()` доступны через ссылку соответствующего подкласса. В `TestShape` показаны корректные приведения типов из примера методички. Вызов метода через общую ссылку по-прежнему использует реализацию фактической фигуры.

### 9. Мебельный магазин

Абстрактный класс `Furniture` хранит материал и цену, а метод `getType()` задает вид мебели. Его наследники `Chair`, `Table`, `Wardrobe` описывают стул, стол и шкаф.

`FurnitureShop` хранит список мебели. Метод `add()` добавляет объект, `printCatalog()` выводит каталог, `buy(index)` удаляет выбранную вещь из списка и возвращает ее. В демонстрации создаются три предмета, затем покупается один из них и выводится оставшийся каталог.

### 10. Транспорт

Абстрактный класс `Transport` хранит скорость и тарифы на перевозку. Наследники `Car`, `Plane`, `Train`, `Ship` задают параметры автомобиля, самолета, поезда и корабля.

Расчет выполняется общими методами:

- Время в часах: расстояние в километрах делится на скорость в км/ч.
- Стоимость перевозки пассажиров: расстояние умножается на число пассажиров и тариф за человека на километр.
- Стоимость перевозки груза: расстояние умножается на массу в тоннах и тариф за тонну на километр.

В `TestTransport` для всех четырех объектов рассчитывается поездка на `1000` км с тремя пассажирами и двумя тоннами груза. Тарифы условные, ограничения вместимости и задержки не моделируются.
